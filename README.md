# 🐾 CatTetris

ネコ好きに受けるテトリス。落ちてくるブロックはすべて猫のポーズで表現され、遊んでいると時々「猫の手」が画面外からひょいと伸びてきて、積み上がったブロックを気まぐれにズラしていきます。

## 遊び方（予定）

- 基本操作は通常のテトリスと同じ（左右移動・回転・ソフトドロップ・ハードドロップ）。
- ブロックの形は標準の7種（I/O/T/S/Z/J/L）だが、見た目はそれぞれ対応する猫のポーズで描かれる。
  - 例: `O`（2×2の正方形）→ 丸まって寝ている猫、`I`（1×4）→ 伸びをしている猫
- ランダムなタイミングで「猫の手」が現れ、積み上がったブロックの一部を1〜2マスほど気まぐれにズラす。理不尽な事故（お邪魔ブロックのような即死級のギミック）にはならないよう、小規模・低頻度・安全確認つきで発生する。
- ライン消去時には「にゃー」という効果音が鳴る。

## 技術構成

- Vanilla JavaScript + HTML5 Canvas（フレームワーク・ビルドツールなし）
- `<script type="module">` によるES Modulesのみで構成。npm/package.json は使用しない
- GitHub Pagesでそのまま公開できる静的サイト構成

## ローカルでの動作確認

このプロジェクトはビルド不要です。`index.html` をブラウザで直接開くだけで動作します。

Canvas/ES Modulesの制約でエラーが出る場合は、簡易サーバーを立てて確認してください。

```bash
npx serve .
```
