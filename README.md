# 🐾 CatTetris

ネコ好きに受けるテトリス。落ちてくるブロックはすべて猫のポーズで表現され、遊んでいると時々「猫の手」が画面外からひょいと伸びてきて、積み上がったブロックを気まぐれにズラしていきます。

🎮 **プレイはこちら:** https://dayonesuke55.github.io/CatTetris/

## 遊び方（予定）

- 基本操作は通常のテトリスと同じ（左右移動・回転・ソフトドロップ・ハードドロップ）。
- ブロックの形は標準の7種（I/O/T/S/Z/J/L）だが、1マスごとに猫の顔（耳・目・鼻・ヒゲ）で描かれる。
  - 種類ごとに耳の形・目の形・毛柄が異なり、7種の「猫種」として見分けがつく（例: `O`→丸顔で眠そうな目、`I`→シャム猫風のマスク柄）。
  - ブロックが盤面に固定された後も顔は消えない。
- ランダムなタイミングで「猫の手」が現れ、積み上がったブロックの一部を1〜2マスほど気まぐれにズラす。理不尽な事故（お邪魔ブロックのような即死級のギミック）にはならないよう、小規模・低頻度・安全確認つきで発生する。
- ライン消去時には「にゃー」という効果音が鳴る。
- 猫種ごとに「なつき度」があり、その猫種を含むラインを消すたびに貯まる。10回消すごとにハートゲージが満タン→レベルアップを繰り返し、レベルに応じてゲージの色が変化（毛色→金→オレンジ→バラ色）していく。ゲームをまたいで記録が残る。
- レベルアップの瞬間、その猫種の顔が画面右のパネルに大きく表示され、猫種ごとに異なる鳴き声（3パターンからランダム）が鳴る。

## 技術構成

- Vanilla JavaScript + HTML5 Canvas（フレームワーク・ビルドツールなし）
- `<script type="module">` によるES Modulesのみで構成。npm/package.json は使用しない
- GitHub Pagesでそのまま公開できる静的サイト構成
  - ビルド不要のため、`main` ブランチのルート (`/`) をそのままPagesのソースに指定するだけで公開可能
  - `.nojekyll` を配置し、GitHub側のJekyll処理を無効化（変換不要な静的ファイルをそのまま配信するため）
  - 全てのアセット参照（`css/`, `js/`）は相対パスのため、プロジェクトページのサブパス (`/CatTetris/`) 配信でもそのまま動作

## ローカルでの動作確認

このプロジェクトはビルド不要です。`index.html` をブラウザで直接開くだけで動作します。

Canvas/ES Modulesの制約でエラーが出る場合は、簡易サーバーを立てて確認してください。

```bash
npx serve .
```
